## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment

The dashboard web client expects:

```bash
BAZARMIO_API_URL=http://localhost:3001
```

Use the staging or production API URL in deployed environments.
